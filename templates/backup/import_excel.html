How Import Works
What happens
  • Each row is read and matched by Loan No
  • New loan nos → inserted
  • Existing loan nos → updated with latest values
  • Customer names auto-created if they don't exist
  • Formulas in Excel are evaluated (data_only mode)
Expected columns
A: Sl.No   B: Loan No   C: Loan Date
D: Name   E: Mobile   F: Ref
G: Due Date   H: Follower
I: Loan Amt   J: Doc Charge
K: Principle   L: Interest
M: Agreement   N: Tenure
O: Due Amt   P: Paid Due
Q: Paid Amt   R: Feature Dues
S: Balance   T: Int %   U: Vehicle Model
V: Vehicle No   W: Doc Status   X: Remarks
Note: This import does not delete existing records. It only inserts new rows and updates existing ones by Loan No. Payments history is not affected.
